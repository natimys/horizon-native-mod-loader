# Community conduct

Be respectful, constructive and specific. Welcome contributors regardless of
experience or background. Critique code and ideas, respect privacy, and give
credit for other people's work.

Harassment, threats, discriminatory abuse, sexual harassment, doxxing and
publishing another person's private information are unacceptable. Do not post
credentials, personal saves or proprietary game files in community discussions.
This applies to project issues, pull requests and other project-managed spaces.

Report concerns privately to the maintainer through the public GitHub profile
linked from the repository owner. If no private channel is available, request one
without naming victims or publishing sensitive details. Maintainers may remove
content, close or lock discussions, warn participants, or restrict participation
according to severity and repeated behavior. Reports will be handled with as
much confidentiality as possible. Maintainers are subject to the same rules.
